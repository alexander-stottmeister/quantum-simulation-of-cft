Widgets

Each page recomputes one thing in your browser and says what it does not show. Each compares its own arithmetic against the JSON that tools/make_data.py wrote with numpy, and shows the comparison as a table with a pass or fail badge and the tolerance written out. Nothing is a stored picture, and no third-party script is loaded.

How the checks work

Every widget computes what it draws from the formulas of the Supplemental Material, in docs/assets/cft.js. The same formulas are implemented independently in tools/make_data.py, with numpy, and their output is committed as docs/data/*.json. At load each page evaluates both and prints a table: in your browser, from make_data.py, the relative difference, and the tolerance being applied.

  • Closed-form quantities are checked at \(10^{-12}\) relative, or exactly 0 for integer counts.
  • The correlator (widget H) is checked at \(10^{-5}\) relative with an absolute floor of \(10^{-12}\), and the floor is the honest part. The browser uses an implicit-QL sweep on the tridiagonal chains where numpy uses eigh; the two agree to about \(4\times10^{-13}\) on the correlator, which is a few units in its last place — but the quantity plotted is a difference of two correlators of order \(0.1\), so that same agreement is only about \(10^{-6}\) of the difference. A relative tolerance alone would be dishonest in one direction or vacuous in the other.
  • The deviation in widget C is checked at \(10^{-9}\), because it is a difference of two nearly equal numbers and loses digits to cancellation.
  • Some rows are marked as transcription checks rather than computations — the Sobolev exponents in widget G, for instance, are quoted from the supplement on both sides. The page says which is which, because a check that cannot fail is worse than no check.

The same comparisons run outside a browser:

node tools/check_js.mjs      # the numbers
node tools/check_pages.mjs   # every page loads and every control sweeps

Controls are real <input> and <select> elements, so Tab and the arrow keys reach everything. Control settings are written into the URL fragment, so a particular configuration can be linked to. Animated widgets start paused when your system asks for reduced motion. Every widget page carries a fallback inside <noscript>: the four priority widgets with a static SVG built by tools/make_figures.py from the same JSON, the rest with a sentence that states the conclusion in words.
